# 测绘计算参考

> 来源：数字测图实习组内手册《测量计算方法》与典型闭合导线算例（12 边闭合导线、1118.3 m；四站水准路线）。
> 与教师要求或教材公式不一致时，以教师和教材为准。

## 一、坐标与单位约定

| 项目 | 本项目采用 |
|---|---|
| 平面坐标系 | CGCS2000 / 3°带，中央子午线 114°E（**EPSG:4547**） |
| 高程基准 | **1985 国家高程基准**（示例基准点 H = 770.208 m） |
| 坐标记法 | **E（东坐标）在前、N（北坐标）在后**，单位 m |
| 方位角 α | **从北起顺时针**，0°~360° |
| 水平角 | 测站点上顺时针；盘左读数即水平角 |
| 角度记录 | 度分秒（″），计算用度（小数） |
| 边长记录 | 读至 **mm**（0.001 m），坐标取至 mm |

必背公式（E 在前、N 在后，方位角从北起）：

```
坐标增量：  ΔE = D · sin(α)        ΔN = D · cos(α)
碎部点坐标： E = E₀ + D·sin(α₀+δ)  N = N₀ + D·cos(α₀+δ)
反算：      D = √(ΔE² + ΔN²)      α = atan2(ΔE, ΔN)
```

常见错：把 sin 和 cos 写反。**北向是 cos**。
度分秒换算（计算器设为度）：`度 + 分/60 + 秒/3600`；反过来 `秒 = 小数部分 × 3600`。

## 二、平面导线测量计算流程

```
外业观测(角度+边长)
   ↓ ① 测角闭合差检核  fθ ≤ 60″√n
   ↓ ② 边长相对闭合差检核  fD/D ≤ 1/2000
   ↓ ③ 角度平差 → ④ 推算方位角 → ⑤ 算坐标增量
   ↓ ⑥ 坐标闭合差 fE、fN、fD → ⑦ 坐标增量平差
   ↓ ⑧ 各点坐标成果表
```

### 闭合差判据

- **测角闭合差** fθ ≤ 60″√n（n 为测站数或边数，按课程口径）。超限 → 检查测站数、盘左盘右、照准与对中。
- **边长相对闭合差** fD/D ≤ 1/2000。超限 → 优先怀疑尺度因子（测距仪常数、棱镜常数、温压改正）与桩号抄错。
- **坐标闭合差** fD = √(fE² + fN²)，按线路长度比例分配到各边（vD = -fD · (ΣD_前 / ΣD)），方向改正同理。

### 角度平差

按闭合差反号等权分配：v_i = -fθ / n（等权），再按测站数加权分配（权 = 测回数）。改正后的角度和应严格闭合，
即 `Σ(α_i + v_i) - (n-1)·180°` 落在 mm 级以内（角度闭合到秒级）。

### 坐标增量平差

改正数按边长比例分配：
```
vE_i = -fE · (ΣD_前 / ΣD_总)
vN_i = -fN · (ΣD_前 / ΣD_总)
```
平差后坐标增量之和应等于 0（等精度条件下 fE、fN 均为 0）。

## 三、水准测量

### 闭合差检核

四等水准：允许闭合差 `f_h = ±12√L` mm（L 为线路长度 km）；三等 `±6√L`；二等 `±4√L`。
路线长度以实测段落累计，单站段不足 1 km 按 1 km 计。

### 高差计算

```
Δh = (a₁ - b₁) + (a₂ - b₂) + ...   视距法或上下丝读数
h_B = h_A + ΣΔh - Σ(高差闭合差改正)
```

双面尺：黑红面读数差应满足 `Δ ≤ 3 mm`（四等）或 `≤ 2 mm`（三等），超限说明读数或照准有问题。

### 精度评定

- 每公里高差中误差：`MΔh = f_h / √L`（mm/km）
- 允许中误差按等级查表；实测中误差大于允许值需重测或加严观测。
- 平差可用间接平差（按测段长度定权），权 = 1/L。

## 四、地物测量与碎部点采集

- 测站法：以测站点为原点，测角 α₀（后视方向）+ 角距（水平角 δ）→ 算碎部点坐标。
- 支距法：量取支距 d 与夹角 → 极坐标法求点。
- 地形图上地物轮廓用 "实描法"：直接在现场按比例尺描绘房屋、道路、水体边界。
- 数字化成图时，**房屋边角点、建筑轮廓转折点**是精度控制关键，必须是实测角点；圆弧类地物可采特征点 + 半径参数。

## 五、精度与成果整理

- 碎部点中误差应满足课程规定；一般平面点位中误差优于图上 0.1 mm（1:500 图 ≈ 0.05 m）。
- **成果表必须含**：点号、E、N、H、测站、观测角、边长、备注。
- **非实测数据必须显式标注**。本项目约定：Google 地图取点等非实测点在图形中加"非实测"说明，
  并在图内写明假设基准与排除的点，不得混入实测成果统计与精度评定。
- 跨源坐标叠加前必须统一到同一基准（见 crs-raster.md 的基准偏移陷阱）。
