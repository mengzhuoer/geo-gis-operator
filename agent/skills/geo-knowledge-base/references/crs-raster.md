# 坐标系、投影与栅格基础

## 一、地理坐标系 vs 投影坐标系

- **地理坐标系**（WGS84、CGCS2000）：经纬度，单位为**度**。量算面积、距离、角度前必须投影。
- **投影坐标系**（EPSG:4547、UTM 带、Albers 等积）：单位为米，可直接量算。

本项目：**CGCS2000 / 3°带，中央子午线 114°E，EPSG:4547**；高程为 **1985 国家高程基准**。
EPSG:4547 在 ArcGIS 中解析为 `CGCS2000_3_Degree_GK_CM_114E`。

## 二、常用投影的选择

| 投影 | 适用 | 说明 |
|---|---|---|
| **UTM 分带**（横轴墨卡托） | 区域尺度、中小范围 | 变形小，量算精度高；必须选对带，否则偏移数百公里 |
| **Albers 等积圆锥** | 大区域统计、面积量算 | 面积误差最小，适合省域/跨省统计 |
| **高斯-克吕格 3°带** | 中国中纬度带状区域 | CGCS2000 常用；带号按中央子午线确定，114°E → EPSG:4547 |
| **兰勃特等角圆锥** | 常用航空/全国地图 | 形状保持好 |

要点：**不同投影的数据不能直接裁切叠加**，必须先重投影到统一坐标系再比较，否则产生错位。

### 带号速查（3°带）

中央子午线 = 带号 × 3（E）。经度 113.5°~116.5° → 中央子午线 114°E → EPSG:4547。

## 三、基准偏移陷阱（重要）

在中国，WGS84、GCJ-02（国测局）、BD-09 之间存在系统性偏移：

- **GCJ-02 相对 WGS84 的偏移量约 500 m 量级**（本项目实测案例约 **559 m**，经度方向偏西）。
- 偏移远超测绘精度容许，**不能**只写"按 WGS84 近似 CGCS2000"就完事——必须做偏移量检验：
  把转换后的点与已知控制点或正射底图比对，若整体偏移量与偏移方向矛盾，则基准假设错误。
- 本项目实例（已独立复核，数值来自实际投影计算而非估计）：
  四个 Google 取点按 WGS84 投影 → E381579.94~381678.29、N4180121.21~4180202.36，
  **四点全部落在**学校正射底图范围（E381492.96~382184.43、N4180066.35~4180536.68）内。
  若改按 GCJ-02 反算 → 四点整体西移 **ΔE = −557.7~−557.9 m**，落到 E381022.27~381120.37，
  **超出底图西界达 372.6~470.7 m**，故判定 GCJ-02 解不成立。
  第五个点（112.665559, 37.745684）→ E382386.47，超底图东界 382184.43 约 **202 m**（偏东约 765 m），故剔除。
- **容许对比**：1:500 图上 0.1 mm ≈ 实地 0.05 m；558 m 偏移高出 4 个数量级，
  绝不能以"WGS84 近似 CGCS2000"略过检验。
- 检验的**前提**：参照物（控制点/正射底图）自身的基准与精度必须可靠；若参照物本身为 GCJ-02
  或粗配准，该检验失效。

## 四、GeoTIFF 与栅格数据

- GeoTIFF 在 TIFF 中嵌入地理坐标（仿射变换 + 投影），是遥感栅格主流格式。
- 关键属性：**像元尺寸**（决定最小可识别地块，30 m 像元 = 900 m² = 0.09 ha）、行列数、坐标系、
  **nodata**（常见 −9999 或 0）。
- **同一网格**：多个栅格做叠加运算时，行列数、仿射变换、坐标系必须完全一致，否则需重采样 + 重投影。
- 像元面积 = 像元长 × 像元宽。

### 重采样选择

| 场景 | 方法 |
|---|---|
| 连续量（NDVI、高程、温度） | 双线性插值 |
| 分类图（土地利用） | 最近邻 |
| 降分辨率聚合 | 分块均值/众数（注意比例因子） |

## 五、DEM 与地形因子

DEM 派生：高程、**坡度**（Horn 3×3 窗口，单位度）、坡向、地形起伏度、**山体阴影**（按方位角与高度角模拟光照）。

- 山体阴影用于专题图叠加增强立体感，不是数据。
- 坡度陡的采坑与排土场具有特征值，是分类模型与复垦方式确定的重要依据。
- **坡向约定**：北=0°，顺时针，与本项目方位角约定一致（从北起顺时针）。

## 六、面积与距离量算

- 投影坐标系下直接用平面几何量算；大范围用等积投影（Albers）或 UTM 带内投影。
- **椭球面积**（如 CGCS2000 / WGS84 椭球面积）适用于跨国界、极区等大范围精确统计。
- 报告面积时注明：投影方式、是否包含 nodata 剔除、是否经几何修复。

## 七、精度表达

- 面积小数位与数据分辨率匹配：30 m 像元不应给出到平方米的面积精度（单像元误差可达 ±0.05 ha）。
- 分辨率与比例尺对应：1:500 地形图图上 0.1 mm ≈ 实地 0.05 m；1:2000 ≈ 0.2 m。

## 八、常见陷阱汇总

1. 地理坐标系下量算面积 → 先投影。
2. 不同投影的栅格直接裁切 → 先重投影。
3. 分类栅格用双线性插值 → 用最近邻。
4. 忽略 GCJ-02 偏移 → 与控制点/底图做偏移量检验。
5. 分类图的类别体系不一致直接比较 → 先建立类别映射表并说明归并规则。
6. 基准期面积为 0 的地类仍计算动态度 → 应留空标注"无数据"。
7. 30 m 数据宣称米级面积精度 → 精度声明与分辨率不匹配。
